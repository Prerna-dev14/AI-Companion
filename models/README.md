# AI Companion - Model Artifacts & Weights

This directory houses local model weights, cache artifacts, and ONNX runtime checkpoints for:
- Speech AI (Whisper STT, TTS acoustic models) - *Phase 3*
- Computer Vision (MediaPipe / Face Landmarker models) - *Phase 4*
- NLP Emotion & Intent classification models - *Phase 5*

> **Note:** Raw audio, video, or user biometric captures are never stored in this directory or persisted to disk.
